# Зелёный чай — другая визуальная система

Комплект из 5 карточек для зелёного индийского чая. Сделан намеренно **не в стиле
остальной библиотеки**: вместо песочного поля с терракотой — тёмно-зелёное поле, золото,
засечный шрифт и фотографии как фон.

| Файл | Что на слайде |
|---|---|
| `01_packshot.jpg` | банка на зелёном градиенте, без надписей |
| `02_origin.jpg` | постер: плантация Ассама во весь кадр, засечный заголовок |
| `03_profile.jpg` | профиль вкуса шкалами: терпкость, сладость, травянистость, аромат |

| `05_kit.jpg` | что в банке и как хранить |

## Чем отличается от остальных карточек

- **Палитра:** #0E3126 (тёмно-зелёный), #D9B65B (золото), #F4EFE2 (бумага) вместо
  бежево-терракотовой.
- **Типографика:** Lora (засечный) в заголовках вместо гротеска Onest. Моноширинный
  остаётся только для служебных подписей.
- **Фон:** фотография на весь кадр на постере, градиент на пакшоте, бумага на слайде
  с рецептом. Внутри одного комплекта чередуются тёмные и светлые слайды — это приём,
  а не случайность.
- **Композиция:** на постере текст живёт поверх фотографии, а не рядом с товаром.

## Что проверено

Тот же аудит, что и для остальных товаров: контраст по фактическим пикселям, наезды
текста, зоны бейджей, читаемость на миниатюре, кегли. Ошибок — 0.

Особый случай: на постере фотография занимает весь кадр, поэтому проверка «текст не
наезжает на товар» для этого макета отключена — иначе она справедливо ругалась бы
на любой текст. Остальные проверки работают.

## О кадрах

Банка, плантация и макро листа сгенерированы локально (ComfyUI, FLUX.3) и вырезаны
скриптом. Это демонстрация системы, а не съёмка реального продукта.
