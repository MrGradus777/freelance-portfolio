# Тестовое: карточка вертикального моющего пылесоса

Формат: 900×1200, JPG. Палитра и структура — строго по ТЗ:
фон #F7F5F0, блоки #DDF3EF, текст #1E2B33, акцент #19B5A5, «грязь» #B5673A.

## Обложки
- 01_cover_light — светлая, ключевые выгоды + чипы УТП
- 02_cover_dark — тёмный контраст #14232B, белый текст, акцент аква
- 03_cover_aqua — насыщенный аквафон #0B7A70, светлый текст

## Слайды
- 04_slide_what_changed — «Было / Стало»: два предмета линейно против одного прибора
- 05_slide_before_after — вид сверху, «до» терракота и «после» аква, чистая полоса
- 06_slide_floors — четыре покрытия в кругах с аква-обводкой, пылесос в центре
- 07_slide_battery — кольцо 80 минут + строка характеристик
- 08_slide_compare — таблица «Швабра / Пылесос / Наш», колонка «Наш» выделена
- 09_slide_kit — комплект с нумерацией

## Примечание по товару
В документе с ТЗ нет чистого рендера товара — только готовые карточки с наложенными
текстами и значками. Товар вырезан с одного из референсов и очищен от наложенного
значка, поэтому на правой грани корпуса видна лёгкая ретушь.
Для продакшена нужен исходный рендер/фото товара без плашек — тогда тот же макет
собирается за минуты и без следов ретуши.
