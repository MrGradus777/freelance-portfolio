# parser-to-db — парсер каталога в базу данных

Демо-проект: сбор данных с сайта, запись в SQLite без дублей и отчёт в CSV.
Демо-источник — учебный каталог `quotes.toscrape.com`, логика легко переносится на любой каталог.

## Что умеет

- Обход N страниц каталога с задержками и понятной обработкой ошибок.
- Извлечение полей: текст, автор, теги, источник.
- Запись в SQLite с `INSERT OR IGNORE` — повторный запуск не создаёт дублей.
- Экспорт отчёта в CSV (разделитель `;`, `utf-8-sig` — открывается в Excel без танцев).
- Сводка в консоль: всего записей и топ авторов.

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate      # Windows: .venv\Scripts\activate

pip install -r requirements.txt

python parser.py --pages 3
python parser.py --pages 10 --out data/report.csv
```

Результат: `data/catalog.db` (база) и `data/report.csv` (отчёт).

## Пример вывода

```
Страница 1: найдено 10, добавлено 10, дублей 0
Страница 2: найдено 10, добавлено 10, дублей 0
Итого добавлено: 20, пропущено дублей: 0
Отчёт сохранён: data/report.csv (20 строк)

Всего записей в базе: 20
Топ авторов по количеству записей:
  Albert Einstein — 10
  J.K. Rowling — 9
```

## Что получает заказчик

- База данных вместо ручного копирования.
- Повторные запуски не плодят дубли.
- Отчёт, который можно сразу отправить в Excel или загрузить в CRM.

## Как адаптировать под заказ

1. `BASE_URL` и `parse_page()` — селекторы под конкретный сайт.
2. Схема таблицы в `init_db()` — под нужные поля.
3. Задержка между запросами — добавить `time.sleep()` при парсинге реального сайта.
4. Для больших объёмов — заменить SQLite на PostgreSQL (тот же SQL, другой драйвер).
